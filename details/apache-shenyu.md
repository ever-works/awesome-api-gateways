## Overview

Apache ShenYu is a Java-native API Gateway designed for service proxy, protocol conversion, and API governance. It sits between clients and backend services, handling routing, traffic control, and protocol adaptation.

## Features

- Service proxy and routing for REST, RPC, and other protocols
- Protocol conversion between different backend protocols
- API governance and policy management
- Dynamic configuration and hot updates
- Plugin system for extensibility (authentication, rate limiting, monitoring, etc.)
- Service discovery integration
- Dashboard for management and monitoring
