## Overview

Insomnia is an open-source API design, debug, test, and mock tool that works locally, on Git, or in the cloud. It supports the most popular API protocols with a developer-friendly UI.

## Features

- User-Friendly Interface: Clean, intuitive desktop application
- Support for Multiple Protocols: REST, GraphQL, gRPC, SOAP, WebSockets, and SSE
- Environment Management: Variables and environments for different deployment stages
- Custom Plugins and Themes: Extensible plugin system and UI customization
- API Mocking: Local mock servers for API development
- Git Integration: Store API specifications in version control
- CLI: Command-line interface for CI/CD integration
- Open Source: MIT license, source available on GitHub

## Pricing

- Free and open source under the MIT license
- Insomnia Plus: Paid features for team collaboration and cloud sync

## Deployment

Desktop applications for macOS, Windows, and Linux; self-hosted options available.
