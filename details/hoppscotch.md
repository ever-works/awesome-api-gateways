## Overview

Hoppscotch is an open-source API development ecosystem that helps developers design, test, and manage APIs with a lightweight and real-time interface.

## Features

- User-Friendly Interface: Clean, minimalist API request builder
- Open Source: MIT license, community-driven development
- Multi-Platform Support: Web app, desktop clients, and mobile support
- Real-Time Collaboration: Team workspaces and shared API collections
- Request Builder: Support for REST, GraphQL, WebSocket, and more
- Environment Variables: Manage variables across different environments
- API Documentation: Generate and share API documentation
- Import/Export: Support for Postman collections, OpenAPI, and more

## Pricing

- Free: Core features for individual developers
- Pro: Paid plan with advanced team features

## Deployment

Web-based application with desktop clients; self-hosted option available.
