## Overview

Paw is a full-featured REST client for macOS that helps developers build, test, and describe the APIs they are building or consuming.

## Features

- User Interface: Native macOS application with elegant design
- Team Collaboration: Shared environments and team workspaces
- Advanced Request Capabilities: Support for REST, GraphQL, and other HTTP-based APIs
- Extensions and Plugins: Extensible plugin ecosystem for custom functionality
- Dynamic Values: Variables and dynamic values in requests
- Code Generation: Generate code in multiple languages from requests
- Environment Management: Multiple environments for development, staging, production
- Import/Export: Support for OpenAPI, Postman collections, cURL, and more
