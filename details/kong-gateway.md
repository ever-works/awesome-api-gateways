## Overview

Kong Gateway is a lightweight, cloud-native API gateway built on NGINX that helps teams manage API traffic. It provides security, authentication, transformation, and analytics capabilities through plugins.

## Offerings

- **Kong Gateway for Open Source**: Open-source version of Kong Gateway
- **Kong Gateway for Kong Enterprise**: Enterprise edition with advanced features
- **Kong Gateway for Kong Konnect**: Cloud-hosted SaaS offering

## Key Features

### Traffic Management
- Basic Traffic Control Plugins
- Simple Data Transformations
- GraphQL support
- Kafka Integrations
- Multi-protocol Plugin Support
- Request Validation
- Advanced Data Transformation
- Advanced Rate Limiting
- Routing Engine

### Security and Compliance
- Basic Authentication
- Advanced Authentication
- Role-Based Access Control (RBAC)
- Basic Authorization (Bot Detection, CORS controls, ACLs)
- Advanced Authorization (OPA)
- Out-of-the-box integration with 3rd party secret management tools
- FIPS 140-2 Compliant Data Planes
- Software Bill of Materials

### Observability and Automation
- OpenTelemetry support
- Developer Portal Service Hub
- API Analytics
- Data Retention Period for Observability: Up to 1 year
- Admin GUI: Self-managed Kong Manager
- Gateway Event Hooks
- Audit Logging
- Declarative configuration for CI/CD pipelines
- API and web UI configuration

### Kubernetes Support
- Integrates with Kubernetes through Kong Ingress Controller
- Kubernetes-native workflows
- Traffic management, transformations, and observability across Kubernetes clusters

## Deployment Options

- On-premises (self-managed)
- Cloud
- Kubernetes
- Serverless environments
- Database-backed and database-free configurations
- Hybrid and cloud-hosted modes

- Enterprise support
- Customer Success Packages (add-on)
