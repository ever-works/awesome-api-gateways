## Overview

Tempreon is a personal memory layer for AI tools, connected over MCP. It enables AI assistants to remember context across conversations and sessions.

## Features

- Cross-LLM memory: Memory that works across different large language models
- Core Imprint: Foundational memory layer for personal context
- Knowledge Vault: Structured storage of learned information and preferences
- Learning System Layer: Continuous learning from user interactions
- MCP integration: Connects via Model Context Protocol to AI tools
