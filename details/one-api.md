## Overview

one-api is an LLM API management and key redistribution system that unifies multiple model providers under a single OpenAI-compatible API. It supports providers including OpenAI, Azure, Anthropic Claude, Google Gemini, DeepSeek, and others, enabling API key management and secondary distribution.

## Features

- Unified API adapter for multiple LLM providers
- API key management and redistribution
- Single executable file
- Docker-ready image for one-click deployment
- English UI
- Key and subscription account management
- Scheduling and failover
- Request logs and usage statistics
